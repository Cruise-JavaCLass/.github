# Security Policy

## Supported Versions

The following versions of the Cruise Management System services are currently supported with security updates:

| Service / Subsystem | Supported Versions | Status |
| :--- | :--- | :--- |
| `Cruise-api` (Microservices Core) | 1.0.x, 1.1.x | :white_check_mark: Supported |
| `Cruise-web` (Web Portal) | 1.0.x | :white_check_mark: Supported |
| `Cruise-pos` (Mobile Android) | 1.0.x | :white_check_mark: Supported |

## Reporting a Vulnerability

We take the security of passenger data, financial transactions, and maritime navigation systems very seriously.

If you discover a security vulnerability within any repository of the Cruise Management System:
1. **Do not** disclose the vulnerability publicly in an issue or pull request.
2. Please report findings via GitHub Private Vulnerability Reporting or email the security engineering team at `security@cruise-system.internal`.
3. Provide a clear description of the vulnerability, steps to reproduce, and affected microservice endpoints or client versions.
4. Our team will acknowledge receipt within 24 hours and provide a remediation timeline.
